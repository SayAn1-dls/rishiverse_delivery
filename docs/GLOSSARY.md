# Glossary

## Terms Used in This Project

**API Route** — A Next.js serverless function under `/pages/api/` that handles HTTP requests server-side.

**Delivery Agent** — A user with the `agent` role who fulfills delivery orders.

**Order Status** — Lifecycle of an order: `pending` → `assigned` → `in-transit` → `delivered`.

**Webhook** — HTTP callback sent by external services (e.g., payment gateway) to notify of events.

**JWT** — JSON Web Token used for stateless authentication via NextAuth.

**MongoDB Atlas** — Cloud-hosted MongoDB cluster used for all persistent data storage.

**Render** — Cloud platform used to host the Next.js frontend and Node server.
