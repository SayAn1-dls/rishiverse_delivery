# Contributing Guide

Thank you for your interest in contributing to Rishiverse Delivery!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/rishiverse_delivery.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit with a clear message: `git commit -m 'feat: add your feature'`
6. Push and open a Pull Request

## Commit Message Convention

Use conventional commits:
- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation changes
- `refactor:` for code refactoring
- `chore:` for maintenance tasks

## Code Style

- Use TypeScript where possible
- Run `yarn lint` before pushing
- Keep components small and single-responsibility
