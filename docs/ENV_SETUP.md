# Environment Variables Setup

Copy this template and fill in your values in Render Environment settings.

## Required Variables

```
MONGO_URL=mongodb+srv://...
NEXTAUTH_URL=https://your-render-url.onrender.com
NEXTAUTH_SECRET=your_secret_here
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
PORT=3000
NEXT_PUBLIC_APP_NAME=RishiverseDelivery
```

Set all secrets in Render under Environment tab.
