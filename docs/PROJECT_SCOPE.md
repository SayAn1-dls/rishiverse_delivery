# Rishiverse Delivery — Project Scope

## Problem Statement
Local delivery businesses lack a unified, affordable platform for managing orders, assigning agents, and tracking deliveries in real-time.

## Solution
Rishiverse Delivery provides a lightweight, full-stack web application for:
- Customers to place and track orders
- Agents to accept and fulfill deliveries
- Admins to manage the entire fleet

## Tech Stack
- *Frontend*: Next.js 14 (App Router), Tailwind CSS
- *Backend*: Next.js API Routes (serverless)
- *Database*: MongoDB Atlas
- *Auth*: NextAuth.js with Google OAuth
- *Hosting*: Render

## Out of Scope (v1)
- Mobile app
- Real-time GPS tracking
- Payment gateway integration
- SMS notifications
